# PathSnap: XGBoost model

XGBoost candidate-arc classifier + HMM/Viterbi route reconstruction.

## Setup
```bash
pip install -r requirements.txt
```
Put the raw dataset at `data/Student folder/` (it contains `train/` and `student_test/`). It is not stored in the repo.

## Run order (from this folder)
| Step | Command | Output |
|---|---|---|
| 1. Dataset inventory | `python src/01_inventory.py` | `results/inventory.csv` |
| 2. Preprocessing (labels, candidates, features) | `python src/preprocess.py` | `data/processed/candidates.csv.gz` |
| 3. Model benchmark (5 families, group CV) | `python src/model_benchmark.py` | `results/model_benchmark.csv` |
| 4. XGBoost baseline | `python src/xgb_baseline.py` | `results/xgb_baseline.json`, `models/xgb_baseline.json` |
| 5. Bayesian tuning, round 1 | `python src/xgb_tune.py` | `results/xgb_trials.csv`, `models/xgb_tuned.json` |
| 6. Bayesian tuning, round 2 (early stopping, repeated CV) | `python src/xgb_tune2.py` | `results/xgb_trials_round2.csv`, `results/xgb_final.json` |
| 7. HMM / Viterbi decoder | `python src/hmm_decoder.py --tune` | `results/hmm_tuned.json`, `models/hmm_config.json` |

`pathsnap_preprocessing.ipynb` walks through steps 1-2 interactively (the script version is `src/preprocess.py`).

## Method summary
- Road network is per trip. Each GPS point gets candidate arcs within 50 m (spatial index); up to 20 nearest are kept.
- Per-point labels are derived from the reference route with a forward-only dynamic program.
- Two train trips (`00000054`, `00000033`) have GPS ~130 m off the reference route, so they are excluded from fitting and CV.
- Classifier: XGBoost, group 5-fold CV by trip. Decoder: HMM with emission = log classifier probability, transition from road-graph hops.

## Results (student_test, 10 trips)
| | Top-1 accuracy | Route continuity |
|---|---|---|
| Classifier only (tuned XGBoost) | 85.3% | 90.0% |
| Classifier + HMM | 93.4% | 99.8% |

Large generated files (`data/processed/`, out-of-fold predictions) are git-ignored and regenerated by the scripts above.
